浏览器的盒模型可以理解成一个套娃，从里到外依次是内容区、内边距、边框和外边距。最里面是元素真正放文字、图片的地方，它的大小主要由 width 和 height 决定；内容区和元素之间隔着内边距，也就是 padding，用来撑开空间；再往外是边框 border，可以设置颜色、样式和宽度；最外面的空白叫外边距 margin，用来控制元素和其他内容之间的距离。如果设置的 width 和 height 只代表内容区大小，那么加上 padding 和 border 后，盒子会变得更大，所以实际开发中经常使用 box-sizing: border-box，让 width 和 height 直接包含内边距和边框，这样计算尺寸会更方便。
